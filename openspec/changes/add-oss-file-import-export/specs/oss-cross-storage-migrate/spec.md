## ADDED Requirements

### Requirement: 跨存储单文件迁移
系统 SHALL 支持将单个文件从一个 OSS 配置迁移到另一个 OSS 配置。系统通过流式传输将文件从源存储读取并直接写入目标存储，不经过本地磁盘。

#### Scenario: 跨存储迁移单文件
- **WHEN** 用户指定源 OSS 配置名、目标 OSS 配置名和文件 ID
- **THEN** 系统从源存储下载文件流，直接上传到目标存储，创建新的 sys_oss_file 记录并返回结果

#### Scenario: 源文件不存在
- **WHEN** 指定的文件在源 OSS 存储中不存在
- **THEN** 系统返回源文件不存在的错误信息

### Requirement: 跨存储批量迁移
系统 SHALL 支持批量迁移多个文件。用户通过提供文件 ID 列表和源/目标 OSS 配置名，系统 SHALL 逐个迁移文件并返回迁移结果。

#### Scenario: 批量迁移多个文件
- **WHEN** 用户提供多个文件 ID、源 OSS 配置名和目标 OSS 配置名
- **THEN** 系统逐个迁移所有文件，返回每个文件的迁移结果（成功/失败及原因）

#### Scenario: 部分文件迁移失败
- **WHEN** 批量迁移中部分文件因网络超时或存储空间不足而失败
- **THEN** 系统继续处理剩余文件，最终返回成功和失败的统计信息

### Requirement: 跨存储全量迁移
系统 SHALL 支持将一个 OSS 配置中的所有文件全量迁移到另一个配置。

#### Scenario: 全量迁移
- **WHEN** 用户指定源 OSS 配置名和目标 OSS 配置名并请求全量迁移
- **THEN** 系统查询源配置对应的所有文件记录，逐个迁移到目标存储

### Requirement: 迁移进度查询
系统 SHALL 支持查询迁移任务的执行进度。

#### Scenario: 查询迁移进度
- **WHEN** 用户提供迁移任务 ID 并请求查询进度
- **THEN** 系统返回任务的当前状态（进行中/已完成/失败）、已处理文件数和总文件数
